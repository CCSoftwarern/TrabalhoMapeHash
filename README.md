# Trabalho Map e Hash

* Controle de Estoque Online:
* Cadastro de produtos com: ID, nome e quantidade em estoque.
* Chave: ID do produto / Valor: Nome e quantidade
* Funcionalidades: adicionar produto, consultar estoque, remover produto

Comandos: 
* Transpilar: npx tsc app.ts
* Executar: node app.js
* Executar servidor Node http-server
